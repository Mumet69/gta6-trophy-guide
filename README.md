The best offline guide and tracker for the 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade; a checklist saved in your browser with export and import; filters by kind and grade; a spoiler setting that hides the 28 hidden trophies until earned; a three-stage roadmap to the platinum (~200 hours, difficulty 4/10); the one potentially missable trophy flagged; and a guide to each trophy in our own words that cites its sources — Exophase and PSNProfiles for the official list and its counts, PowerPyx for the roadmap and the per-trophy steps. Where a trophy is not yet confirmed, the guide says so instead of guessing.

## Run it

Serve `app/` with any static server and open `app/index.html` in a desktop browser. No build step, no network requests — it works with the network off.

```sh
node serve.ts
# then open http://localhost:8080
```

Hand the entry in with the program at the root:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
